# SCRIPTS.md — Operator Cheatsheet

> Every script ends a failure with one line after `❌` or `✖` that says what happened and what to do next. `PRECAST_DEBUG=1` adds the full error.

> Every `pnpm` script at the repo root, grouped by lifecycle.

---

## Setup & Install

| Script                      | Command                                  | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `pnpm bootstrap`            | `node scripts/bootstrap.mjs`             | New project: prompts name, auto-picks a free consecutive port block, asks LLM provider (incl. **AgentBase Models** — collects gateway URL/token URL/client id/secret/model into `.env`; `--agentbase-client-secret=later` leaves the secret line empty for the person to paste in by hand and skips the database until `pnpm db:provision`) and APC theme, renames placeholder, updates deps, blank git repo on `develop`                                                                                                                                                                                    |
| `pnpm rename <name>`        | `node scripts/rename-project.mjs <name>` | Replace the `precast` placeholder with your project name only                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `pnpm set-ports`            | `node scripts/set-ports.mjs`             | Set the two apps' ports (`--mastra=45000 --web=45001`, each optional; or `--auto` to pick a fresh free consecutive pair in 45000–49100). Rewrites `.env`, `.env.example`, the env schema defaults, the Dockerfiles, the pnpm scripts and the port-stating docs in one pass.                                                                                                                                                                                                                                                                                                                                  |
| `pnpm set-theme [name]`     | `node scripts/set-theme.mjs`             | Choose the APC Design System theme — `stockholm`, `prague`, `arctic`, `nova`, `melbourne`. No argument lists them and shows the current one. Preview: https://apc-design-system.917v.dev                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `pnpm theme:build`          | `node scripts/build-apc-theme.mjs`       | Regenerate `apps/web/app/theme/apc-themes.css` from `apc.tokens.json`. `--check` fails when the committed CSS is stale (CI guard). Run after re-importing tokens from Claude Design                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `pnpm deps:update`          | `node scripts/update-deps.mjs`           | Update deps to latest compatible (`--latest` / `--dry` / `--no-verify`), pin the AI SDK to Mastra's provider, verify                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm emit:import-manifest` | `node scripts/emit-import-manifest.mjs`  | Re-derive `agentbase.import.json` `requiredEnv` from the env schema (run after changing `packages/shared/src/env.ts`; WEB-005 guards it)                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `pnpm precast:version`      | `node scripts/precast-lock.mjs`          | Print which Precast release this project was derived from (reads `precast.lock.json`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `pnpm precast:update`       | `node scripts/precast-update.mjs`        | Pull later Precast improvements in. Check-only by default; `--apply` writes the safe changes, `--force` also takes conflicts, `--adopt` records a baseline for a project that predates provenance. See [MIGRATIONS.md](MIGRATIONS.md)                                                                                                                                                                                                                                                                                                                                                                        |
| `pnpm connect`              | `node scripts/connect-agentbase.mjs`     | Connect an existing project to an AgentBase Application and prove it before writing: the token URL accepts the id and secret, the API lists the models published to the Application, the chosen model is one of them; then the five values go into `.env`. Asks for anything missing (secret typed hidden), or takes the same `--agentbase-*` flags as bootstrap; the secret can also come from the `AGENTBASE_CLIENT_SECRET` environment variable, so it never sits on a command line. `--check` verifies what `.env` holds and writes nothing. Every failure is a sentence naming where in Studio to look. |
| `pnpm db:provision`         | `node scripts/provision-db.mjs`          | Get a Postgres database with its own scoped login and write `DATABASE_URL` into `.env` once the new credentials connect. Asks the database agent on AgentBase (Hannibal) through the Application in `.env`, so nobody needs a database credential; with `PRECAST_RDS_SUPERUSER_URL` (or `--superuser-url=`) in the shell it goes to the server directly instead. `--label "what you are building"` names the database. Never prints the password.                                                                                                                                                            |
| `pnpm forget-secret`        | `node scripts/forget-secret.mjs`         | Remove this project's secrets from the session logs on this computer after one was pasted into the Claude Code chat: every copy of the values in `.env` (the AgentBase client secret, database passwords, the local tokens) in Claude Code's folder, its temporary folder and the project's own files is overwritten in place with a marker of the same length. `.env` keeps them. Files changed in the last 7 days; `--all` for every file. It cannot reach what was already sent to the model provider.                                                                                                    |
| `pnpm install`              | `pnpm install`                           | Install all workspace dependencies                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `pnpm setup`                | `pnpm install && pnpm build`             | Full setup from clean checkout                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |

## Proof of Concept (see it run)

| Script            | Command                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------- | ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm poc`        | `node scripts/poc.mjs`          | **The "show me something" command.** Checks Node, fills missing local secrets, stops early when `DATABASE_URL` is the placeholder, builds the same production bundles the Dockerfiles build, starts both apps as background Node processes on 127.0.0.1, waits for each health endpoint and for sign-in, and prints the URLs. No container runtime. Only the web app runs when `PRECAST_LOCAL_AGENTS=0` (AgentBase hosts the agents). `--no-build` restarts on the last build; `--timeout=` changes the 180 s health wait. A failure prints the app's last log lines. |
| `pnpm poc <app>`  | `node scripts/poc.mjs web`      | **Refresh just what changed**: rebuilds that app, replaces its process, health-checks and re-prints the URLs. The other app keeps running.                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `pnpm stop`       | `node scripts/poc.mjs --stop`   | Stop both apps (or the one named).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `pnpm logs`       | `node scripts/poc.mjs --logs`   | The last 60 lines each app wrote (or the one named), from `.precast/run/`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `pnpm verify`     | `turbo run typecheck lint test` | **The pre-push check.** What CI runs on every push and PR — typecheck, lint and unit/integration tests across the workspace                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `pnpm verify:poc` | `turbo run typecheck`           | The reduced PoC check (typecheck only) — see CLAUDE.md §4.2.1                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `pnpm verify:all` | `verify` + `build` + `test:e2e` | Everything, including a production build and the Playwright suite. Slower; use before a release or when touching the build                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `pnpm smoke:chat` | `node scripts/smoke-chat.mjs`   | **The end-to-end chat round trip** (SMOKE-016). Sends a real message through the running agents API to a real model and prints the reply. Needs a running stack (`pnpm poc`) and a configured gateway model (`AGENTBASE_LLM_MODEL` plus the Application credentials); not part of CI. `--agent`, `--url`, `--text` override the defaults                                                                                                                                                                                                                              |

> Precast builds **proof of concept first** (CLAUDE.md §4.0): smallest runnable slice → show the user → collect feedback → _then_ harden with the full test + doc bar. `pnpm poc` exists so that first loop is one command ending in a URL.
>
> **After every substantial previewable change, refresh the preview and re-show the URL** (CLAUDE.md §4.0). Use `pnpm poc <app>` for speed: a running app keeps serving the build it started with, so only a rebuild reflects the change.
